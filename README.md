# Genshu 设计日志（公开版）

## 这套日志的维护纪律（原文摘自设计仓）

- 本目录是 append-only 决策史志——回答「当时为什么这么定」
- 新增设计文档或变更状态，必须同 PR 更新索引行
- 同主题冲突时，号大者胜；号被占用时后到者用字母后缀
- 状态取值：`落地` · `部分落地` · `实施中` · `设计定稿·待实施` · `实验` · `暂停/收缩` · `被取代→N号`

## 诚实边界

- 主题文是**整理后的叙述**，索引是一行式原文摘要；设计文档全文留在私有仓，不随本仓发布
- 涉及自托管基础设施细节与个别第三方业务的内容**未收录**（脱敏取舍，不是没有）
- 台账状态如实：补丁链目前**全部 upstream-pending**——语义纯通用、以上游 PR 为目标形态，本地补丁链为过渡载体；未合上游就是未合上游，不冒充
